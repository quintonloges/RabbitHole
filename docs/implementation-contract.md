# Internal implementation contract

Shared namespace `RabbitHole.Domain`, entities in `apps/api/Domain/Models.cs`. EF context `RabbitHole.Data.AppDbContext` exposes Topics, Sources, Items, States, Notes, Documents, Sections, Holes, Nodes, Prompts, Attempts, Editions, Entries, Jobs, Settings, AiResults. JSON camelCase, IDs UUID strings, dates ISO UTC, null dates remain null. List<Guid> fields use JSON text converters for cross-provider tests. Production PostgreSQL, optional SQLite only for deterministic integration tests/local test harness.

Register `AddIngestion()` and `AddDocuments()` and `AddAi()` service extension methods; route mapping `MapIngestionEndpoints()`, `MapDocumentEndpoints()`, `MapAiEndpoints()`. These extensions are implemented in namespace RabbitHole.Features (ingestion implementation may be in RabbitHole.Ingestion). Use `partial class Program` for WebApplicationFactory. Ingestion external HTTP should be injectable behind `IRemoteFetcher`; tests replace this boundary, never app logic.

Item DTO: every item list entry is ContentItem properties plus `state: ItemState`, `topics: Topic[]`, `sourceName: string`, optional `reason: string`, `evidenceItemIds: string[]`. GET /api/items and /api/search return `{items, total}`. GET /api/items/{id} returns item DTO plus `notes`, `related` (item DTOs); body plain text. POST /api/items/{id}/notes accepts {body,quote?,locator?}. PATCH /api/items/{id}/state accepts partial {saved,read,dismissed,understood,progress,opened,feedback}. PATCH /api/items/{id} accepts title,author,topicIds.

GET /api/discover/today returns {id,day,items,total}; POST /api/discover/refresh-edition same; GET /api/discover/more adds bounded items, same output. GET /api/discover/surprise item DTO (404 if empty). GET /api/items/{id}/related returns item DTO array.

GET /api/topics array. POST /api/topics accepts Topic fields; PATCH/DELETE /api/topics/{id}. GET /api/sources array. POST /api/sources accepts {name,kind,url,query,topicIds,intervalMinutes,resultLimit,enabled}; PATCH/DELETE /api/sources/{id}. POST /api/sources/{id}/refresh returns IngestionJob; POST /api/sources/{id}/test checks actual adapter without importing; GET /api/jobs array. POST /api/items/import-url {url,title?} returns ContentItem. GET /api/research/search?provider=openalex|arxiv&q=... returns `{items: NormalizedItem[],warning?}`; POST /api/research/import {provider,providerId} re-fetches authoritative provider record, never trusts invented client metadata.

GET /api/holes array with nodeCount/rootTitle. POST /api/holes {title?,itemId?,question?} returns {id,...}. GET /api/holes/{id} returns RabbitHole fields plus nodes (each includes item DTO or null). POST /api/holes/{id}/nodes {parentId,itemId?,question?,rationale?} returns RabbitNode; POST /api/holes/{id}/navigate {nodeId}; PATCH {title}; DELETE actual hole.

GET /api/library/books returns LibraryDocument[]; POST multipart /api/library/books/upload field `file` returns {document,sections}; GET /api/library/books/{id}/sections array; GET /api/library/books/{id}/file; PATCH /api/library/books/{id} {title,author}; POST /api/library/books/{id}/sections {title,startPage,endPage} creates user PDF range (must preserve existing page items).

GET /api/practice/prompts and /api/practice/due arrays with itemTitle and attempts; POST /api/practice/prompts {itemId,kind?} creates source-linked reflection. POST /api/practice/prompts/{id}/attempts {response,rating:again|hard|good|easy|skip} returns prompt with updated due. GET/PATCH /api/settings simple object {editionSize:25,serendipity:0.15,freshness:0.5,practiceEnabled:false,theme:system,aiEnabled:false}; GET /api/system returns health/counts/configuration state. POST /api/export JSON all user-owned state without secrets/files. GET /api/ai/status configuration; POST /api/items/{id}/ai {action:summary|connections|challenge|lesson|critique,response?,relatedItemId?} returns {text,evidenceItemIds,model,createdAt}.

General errors ProblemDetails {title,detail,status}, loading/error states required. No production test fixture seeding. Starter topics only; preset feeds user-selected and verified separately. Source deletion retains items/state. External text plain text only; embeds constructed from validated provider IDs/URLs and click-to-load for privacy.
